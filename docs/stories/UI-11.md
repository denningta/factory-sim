# UI-11: More equipment models

**Story:** As a manufacturing engineer, I want racks, conveyors, pallets and CNC cells to look like the real thing so that the whole line reads like my floor, not only the benches.

## Acceptance criteria

- [ ] New registry models, each passing the contract test: `cnc-enclosure` (router cell with glass front and spindle), `flow-rack` (shelves that show queued parts in slots), `roller-conveyor` (rollers and direction chevrons), `pallet-source` (pallet with raw stock) and `shipping-sink` (pallet that stacks finished parts)
- [ ] With no `model` set, buffers, conveyors, sources and sinks default to these models
- [ ] Screenshots in `docs/screenshots/UI-11/`: library preview of each model
