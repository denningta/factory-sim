# UI-10: Trend charts for WIP, throughput and utilization

**Story:** As a manufacturing engineer, I want to see how WIP, throughput and utilization develop over the run, so that I can tell when the line settles, when a queue builds and which station falls behind.

## Acceptance criteria

- [ ] The run session records a **stats sample** at a fixed simulated interval (run length / 200 by default), with a bounded history (at most 500 points; older points are thinned evenly). Samples are recorded with animation on or off. Test: count, bound and evenly spaced times
- [ ] **Charts** on the Results screen, in a bottom row as in the control-room reference: WIP over time per product (stacked area), throughput over time (rolling units/hr, line) and station working % over time (one line per station, bottleneck emphasised)
- [ ] The warm-up period is shaded on every chart and excluded from every figure
- [ ] Charts update live while the run plays, at most 4 times a second, without per-frame React state; at the end of the run they show the full history
- [ ] Chart colours, fonts and grid come from the active theme (UI-9); product colours are the products' own; switching theme restyles the charts
- [ ] Each chart has a title, axis units and a legend; hovering shows the values at that time. Tests: series count and legend names per chart
- [ ] Screenshot in `docs/screenshots/UI-10/`: Results after a reference-model run, dark theme
